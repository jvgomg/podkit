# Archived (resolved) questions

Questions whose resolution has been recorded as a principle, feature, or
spike. Files in this directory retain their original framing plus a final
**Resolution** section explaining the outcome and linking to where the
decision now lives.

This directory exists so that the *reasoning* behind a decision is preserved
even after the active question is no longer open. Future contributors can
trace why a particular design works the way it does.

To archive a question, see the workflow in
[`../README.md`](../README.md#resolving-a-question).
