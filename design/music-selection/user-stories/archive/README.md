# Archived user stories

Stories that are solved, out-of-scope, or superseded. Each archived story
retains its original framing plus a final **Resolution** section explaining
the outcome and pointing at where the work now lives.

The archive exists so the reasoning behind decisions is preserved — including
the decision *not* to solve something here.

To archive a story, see the workflow in
[`../README.md`](../README.md#resolving-a-story).
